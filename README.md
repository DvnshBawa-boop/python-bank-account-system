# python-bank-account-system
A beginner friendly Python banking and authentication system built to practice conditionals, loops, string manipulation, user input, and basic account operations.

## Features

- User name and date-of-birth input
- Basic age verification
- PIN authentication
- Maximum 3 PIN attempts
- Deposit money
- Withdraw money
- Check account balance
- Basic input-based menu

## Concepts Practiced

- Variables
- User input
- Type conversion
- Strings and slicing
- If/else statements
- While loops
- Nested conditions
- Break
- Pass
- Basic validation

## Note

This is an educational project created while learning Python.
It is not intended to provide real banking or security functionality.
